# 센서 데이터 통합 대시보드 (교육용)

스마트폰 phyphox 앱으로 측정한 센서 데이터(가속도, 조도, 기압 등)를 PC에서 그래프와 통계로 보여 주는 Tkinter 프로그램입니다. 비싼 실험 인터페이스 장비 없이 학교 과학실이나 학부 실험실에서 쓸 수 있는 데이터 수집·분석 도구를 목표로 합니다.

## 주제

- 물리 원리: 센서 신호 측정과 변환 (가속도계, 조도 센서, 기압 센서), 단진자 운동, 기압과 고도의 관계
- 알고리즘: 데이터 정규화와 실시간 동기화, 이상치 제거, 이동평균, FFT 주파수 분석
- 개발 방식: 바이브 코딩

- [x] 채널 선택, 채널별 그래프

- [x] 이상치 제거 (Hampel 필터), 이동평균

## 설치

Python 3.9 이상이 필요합니다. Tkinter는 윈도우용 Python에 기본으로 들어 있습니다.

```
pip install -r requirements.txt
```

## 사용법

```
python make_sample_csv.py
python sensor_dashboard.py sample_pendulum.csv
```

'CSV 열기' 버튼으로 다른 파일도 열 수 있습니다. 왼쪽에서 그래프에 표시할 채널을 고르세요.

phyphox에서 측정한 데이터를 쓰려면: 앱에서 측정 → 오른쪽 위 ⋮ → 데이터 내보내기 → CSV (쉼표, 소수점) → PC로 옮겨서 열기.

왼쪽 '처리'에서 이상치 제거, 이동평균 창 크기, 기압 → 고도 변환을 조절할 수 있습니다. 빨간 ×는 이상치로 판단해서 바꾼 점입니다. '엑셀로 내보내기'를 누르면 원본·처리값·이상치 표시(data 시트)와 통계(summary 시트)가 저장됩니다.

### 실시간 연결

1. 폰과 PC를 같은 와이파이에 연결합니다.
2. phyphox에서 실험(예: 가속도(g 없이))을 고르고 오른쪽 위 ⋮ → '원격 접속 허용'을 켭니다. 화면 아래에 주소(예: http://192.168.0.10:8080)가 나옵니다.
3. 대시보드의 'phyphox 주소'에 그 주소를 입력하고 '실시간 연결'을 누릅니다.
4. '● 기록 시작'과 '■ 기록 정지'로 원하는 구간만 기록한 뒤 엑셀로 내보낼 수 있습니다.

폰이 없으면 '데모(시뮬레이션)'로 같은 기능을 시험할 수 있습니다.

```
python sensor_dashboard.py --demo
```

## 계산 방법

- **이상치 제거 (Hampel 필터)**: 각 점 주변 창 안의 중앙값과 MAD(중앙값 절대편차)를 구해, 중앙값에서 3×MAD 넘게 벗어난 점을 중앙값으로 바꿉니다. 매끄러운 곡선의 꼭짓점이 잘못 걸리지 않도록 신호 전체의 노이즈 크기를 하한으로 둡니다.
- **주 주파수**: 시간 간격을 균일하게 다시 샘플링하고, 평균과 직선 추세를 뺀 뒤 해닝 창을 씌워 FFT를 합니다. 가장 센 봉우리 주변 3점에 포물선을 맞춰 주파수를 보정하고, 봉우리가 뚜렷하지 않으면(노이즈뿐이면) 표시하지 않습니다.
- **기압 → 고도**: 국제표준대기 공식 h = 44330 × (1 − (p/p₀)^0.1903), 첫 측정값을 0 m로 둡니다. 해수면 근처에서 1 hPa ≈ 8.3 m입니다.
- **실시간 수집**: phyphox의 /config로 버퍼 이름을 알아내고, `/get?acc_time=마지막시각&accX=마지막시각|acc_time` 형식으로 새로 쌓인 값만 0.2초마다 가져옵니다. 수집은 별도 스레드에서 하고, 잠금(lock)이 걸린 공유 버퍼를 GUI가 0.2초마다 읽어 그립니다.

## 예제 데이터 검증

| 예제 | 기대값 | 대시보드 결과 |
|---|---|---|
| 진자 (줄 길이 0.65 m) x축 | 주파수 0.618 Hz (T = 2π√(L/g)) | 0.619 Hz |
| 진자 y축 (줄 방향) | 주파수 2배, 1.237 Hz | 1.236 Hz |
| 계단 3층 오르기 | 고도 +9 m | +9.0 m |
